BrainScan AI

About BrainScan AI

AI-powered brain tumor classification and segmentation system designed for MRI image analysis.

Project Overview

BrainScan AI is a medical imaging system that helps detect brain tumors from MRI scans using deep learning models. The system analyzes uploaded MRI images and predicts whether a tumor exists and identifies its category.

Tumor classification - uses Effiecent net pre trained model segmentation - uses EffiecentNet as encoder and customed netword for the decoder of the Unet Architecture

Features

  • Brain tumor detection
  • MRI image classification
  • Tumor segmentation
  • Fast AI prediction
  • Responsive interface
